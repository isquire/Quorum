CSV format

The CSV must include a header row. Required columns: email, full_name, role.

Optional columns: is_active, is_voting_member, is_active_member, family_group, committees, password.

  • Existing users (matched by email) will be updated. Password is only changed if a new one is provided (8+ chars).
  • New users will be created. A password column with at least 8 characters is required for new users.
  • Boolean fields accept: yes/no, true/false, 1/0. Blank defaults to yes.
  • Valid roles: admin, pastor, deacon, trustee, secretary, treasurer, assistant_treasurer, member.

Tip: Download the current user list as a starting point.

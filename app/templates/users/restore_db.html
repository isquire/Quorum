Warning: Restoring a database will replace all current data with the contents of the uploaded file. A backup of the current database will be saved automatically before the replacement. After restoring, you should restart the application.
How it works
  1. The current database is automatically backed up before replacement.
  2. The uploaded file is validated to ensure it is a valid SQLite database.
  3. The current database is replaced with the uploaded file.
  4. You should restart the application after restoring.

Tip: Download a backup before restoring, just in case.
